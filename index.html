xoyoer 的个人工具

小g邮件流水 Gmail

把个人收件箱按天整理，留下需要处理的事和值得回看的内容。

本工具由 xoyoer 维护，仅供维护者本人使用。它通过 Google 官方 Gmail API 读取指定日期的个人收件箱邮件，生成中文分类与摘要，并保存到维护者自己的资料库。

它会做什么

  • 按北京时间整理指定自然日的收件箱邮件。
  • 读取发件人、主题、接收时间、邮件标识、标签及可读正文，用于个人归档。
  • 在启用 AI 摘要时，将需要整理的邮件材料交给 Google Antigravity 处理，再保留整理结果。
  • 区分需要关注的邮件和普通促销等信息；无法读取或判断的内容明确保留为待查看。

授权范围

仅请求 https://www.googleapis.com/auth/gmail.readonly。本工具不发送、回复、转发或删除邮件，不改动标签和已读状态，也不创建草稿。邮件附件内容不属于当前自动摘要范围。

这是个人工具的公开说明页，不是邮件服务入口。此站点不提供邮箱登录，也不接收或展示邮件数据。Google 授权由维护者在自己的设备上发起。

数据与维护

邮件访问、AI 处理、保存与删除方式详见隐私政策。摘要仅作个人整理参考，具体使用边界见使用条款。

维护者：xoyoer 的 GitHub 主页。本工具与 Google 没有隶属关系；Gmail 和 Google Antigravity 为各自权利人的产品名称。
